# hieuday - Bài tập Lập trình JavaScript

Kho lưu trữ bài tập thực hành môn Lập trình JavaScript.

## Danh sách bài thực hành

### 1. Lab 2: JavaScript cơ bản
- **Giao diện HTML**: [index.html](index.html)
- **Nội dung**: Kiểm tra số chẵn/lẻ, tính tiền điện lũy tiến, tính lương theo chức vụ, bảng cửu chương, kiểm tra số nguyên tố.

### 2. Lab 3: JavaScript nâng cao & Xử lý hàm, chuỗi
- **File script**: [lab3.js](lab3.js)
- **Giao diện HTML**: [lab3.html](lab3.html)
- **Nội dung**:
  - **Bài 1**: `kiemTraSoChan(n)` - Kiểm tra số chẵn.
  - **Bài 2**: `tinhTienDien(kwh)` & `tinhSoDien(tien)` - Tính tiền điện lũy tiến 3 bậc và tính ngược số điện từ số tiền đã cho.
  - **Bài 3**: `tinhLuong(chucVu, ngayCong)` - Tính lương theo hệ số chức vụ (Intern, Staff, Senior, Manager).
  - **Bài 4**: `chuanHoaCau(str)` - Chuẩn hóa khoảng trắng, dấu câu (. , ! ?), viết hoa đầu câu (hỗ trợ tiếng Việt có dấu).
  - **Bài 5**: `calculator(a, b, phepTinh)` - Máy tính các phép toán `+`, `-`, `*`, `/` (có bắt lỗi chia cho 0).
